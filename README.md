# 🧮 BMI Calculator App

A simple and modern Flutter app that helps users calculate their Body Mass Index (BMI) and understand their health category instantly.  
Designed with a clean UI and responsive layout for an intuitive experience.

## 🚀 Features
- Real-time BMI calculation  
- Clear health status (Underweight, Normal, Overweight, Obese)  
- Simple and minimal design  
- Lightweight and fast  

## 🛠️ Built With
- Flutter 💙
- Dart
